Amazon UK Application Helper v4

Chrome / Edge: Extract the ZIP, open chrome://extensions or edge://extensions,
enable Developer mode, click Load unpacked and select this extracted folder.
Reload both the dashboard and Amazon tabs after installation or updates.
Alternatively, install the userscript in Tampermonkey. Use one helper only.

Save your candidate profile and CV on the dashboard. Confirm eligibility answers
only if they are accurate. Click Apply with browser pop-ups allowed.
The helper receives the selected job, shift and candidate profile locally through
extension/userscript storage. No Amazon password is passed or required.
Keep the Amazon tab open and sign in directly on Amazon if asked.

The helper fills known fields, attaches the saved CV to identifiable CV inputs,
uses normal Next/Continue controls, and pauses at assessment, final submission,
unknown required questions, login, OTP and CAPTCHA. It does not change Amazon's
feature flags or forge application/assessment state. Shift reservation is only
confirmed by Amazon, never by saving a dashboard record.

Amazon can change its forms. A displayed pause requires your input; it is not
proof an application was submitted. Private profile handoffs expire in 30 minutes.
